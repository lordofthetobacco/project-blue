# Golden vectors (protocol version 4)

Generated by `tests/golden.rs` with `BLUE_BLESS=1 cargo test`; do not edit by hand.
Each `<name>.bin` holds the exact bytes. Values are Rust `Debug` output: floats are
binary32 printed in shortest round-trip form, `None`/`Some(x)` are optional fields,
and `PlayerSet`s are listed as `(player_id, state)` pairs. Spec: `docs/netcode/protocol.md`.
